상세페이지 기준으로 보면, 정식판은 고객이 살 이유를 먼저 정한 다음 그 이유에 맞춰 6·8·10장 구성과 장면을 짭니다. mini는 정해진 6장 틀에 맞춰 바로 만들어요.

mini는 상세페이지를 1080×2160px 6장으로 만들고, 순서는 히어로 → 사용 상황 → 핵심 기능 → 장점 → 구성·스펙 → FAQ입니다. 생성 전에 장마다 들어갈 헤드라인과 이미지 내용을 표로 보여드리고, 확인을 받은 뒤 한 장씩 만들어요. 장수를 바꾸고 싶다고 하시면 중간 장을 늘리거나 줄일 수 있습니다. 정식판은 FAQ도 다르게 만들어요. 구매 직전에 망설이는 지점을 질문으로 뽑아서 정보 중심 레이아웃으로 정리합니다.

강의는 격차의 김머신 「이커머스의 정석」입니다. 강의 링크: [격차 · 이커머스의 정석 — 김머신](https://www.gykcha.com/html/class_detail.php?it_id=1673617370)

수강생 코드는 여기에 넣으셔도 풀리지 않아요. 지금 mini에는 코드 인증이나 자동 잠금 해제 기능이 없어서 코드를 따로 보내실 필요가 없습니다. 정식판은 운영자가 수강생에게 별도 설치 자료로 줍니다.

- **비공개 저장소 설치 주소를 받은 경우:** 운영자가 허용한 GitHub 계정으로 로그인하고, 그 주소를 플러그인 마켓플레이스에 추가한 다음 앱을 다시 시작해서 설치하시면 됩니다.
- **ZIP 파일을 받은 경우:** 로컬 플러그인으로 등록해서 설치합니다.

mini는 지우지 않고 그대로 두셔도 됩니다. 정식판을 설치하기 전이라도 mini로 상세페이지를 끝까지 만들 수 있어요.
