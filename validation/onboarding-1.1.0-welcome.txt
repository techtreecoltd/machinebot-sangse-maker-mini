머신봇 상세 메이커 mini는 제품 사진으로 썸네일, 누끼컷, 연출컷, 상세페이지를 만들어 주는 무료 공개 버전이에요. 지금 상태로도 바로 쓸 수 있어요.

**사용 순서**

1. **제품 사진을 올려 주세요.** 제품이 선명하게 보이는 정면 사진이면 충분해요. 측면 사진, 포장 사진, 제품명, 꼭 넣고 싶은 특징을 함께 주면 결과가 더 정확해져요.
2. **원하는 결과물을 평소 말투로 말해 주세요.**
   - “이 사진으로 메인 썸네일 한 장 만들어 줘.”
   - “이 제품 상세페이지 6장 만들어 줘.”
   - “이 중국어 상세페이지를 한국어로 바꿔 줘.”
3. **결과를 보고 고칠 부분을 말해 주세요.** “2번 이미지 문구를 더 짧게”, “1번 배경만 밝게”처럼 이미지 번호와 바꿀 점을 함께 말하면 돼요. 상세페이지는 구성표를 먼저 보여드리고, 확인을 받은 뒤 이미지를 만들어요.

**따로 말하지 않으면 이 기본값으로 만들어요**

| 결과물 | 기본 구성 |
|---|---|
| 메인 썸네일 | 1장, 1:1, 흰 배경 제품컷 |
| 썸네일 세트 | 메인 1장 + 서브 5장 |
| 누끼컷 | 흰 배경 1장 |
| 연출·실사용컷 | 4장 |
| 기능 설명 컷 | 3장 |
| 상세페이지 | 6장, 1080×2160px |
| 전체 패키지 | 위 결과물을 모두 묶어 순서대로 제작 |

수량, 비율, 스타일을 직접 말하면 그 요청대로 만들어요. 무엇부터 만들지 모르겠다면 “뭐부터 만들까?”라고 물어보세요. 처음에는 메인 썸네일이나 상세페이지 6장으로 시작하는 경우가 많아요.

상시 연결은 켜지 않아도 사용에 문제없어요. 나중에 원할 때 “상시 연결 켜 줘”라고 하면 새 대화에서도 판매 이미지 요청이 mini로 바로 연결되도록 설정해 드릴게요.

준비가 됐다면 제품 사진 한 장부터 올려 주세요.
