# 결과물과 기본값

사용자가 수량·비율·스타일을 말하면 그대로 따른다. 말하지 않은 부분만 아래 기본값을 쓴다.

| 결과물 | 기본 수량·규격 | 만드는 방식 |
|---|---|---|
| 메인 썸네일 | 1장, 1:1 | 흰 배경 스튜디오 제품컷. 모델컷이나 문구를 원하면 그대로 반영 |
| 썸네일 세트 | 메인 1장 + 서브 5장, 1:1 | 서브는 각도·디테일·구성품·사용 모습을 한 장씩 |
| 누끼컷 | 1장, 1:1 | 흰 배경, 부드러운 스튜디오 조명, 자연스러운 바닥 그림자 |
| 연출·실사용컷 | 4장, 1:1 | 제품이 쓰이는 장소와 손·사람이 사용하는 모습 |
| 효용·기능 시각화 | 3장, 1:1 | 사용자가 알려준 기능을 화살표·흐름선·확대 컷으로 |
| 상세페이지 | 6장, 1080×2160px | [상세페이지](detail-page.md) |
| FAQ 이미지 한 장 | 1장, 1080×2160px | [상세페이지](detail-page.md)의 FAQ |
| 외국어 상세페이지 재제작 | 6장, 1080×2160px | [상세페이지](detail-page.md)의 재제작 |
| 전체 패키지 | 누끼 1 + 썸네일 세트 6 + 연출 4 + 효용 3 + 상세 6 | 목록을 확인받은 뒤 누끼 → 썸네일 → 연출 → 효용 → 상세 순서로. 완성한 누끼를 이후 이미지의 제품 참조로 쓴다 |

## 무엇을 만들지 모를 때
