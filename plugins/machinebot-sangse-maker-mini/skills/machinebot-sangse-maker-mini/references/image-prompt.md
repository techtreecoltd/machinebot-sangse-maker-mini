# 이미지 프롬프트

이미지마다 아래 4칸으로 쓴다.

1. 제품: 참조 사진 속 제품. 모양·색·로고를 그대로 유지
2. 장면: 배경, 구도, 조명, 비율
3. 문구: 이미지에 넣을 글자를 따옴표로 정확히. 없으면 "글자 없음"
4. 유지: 이번 이미지에서 꼭 지킬 제품 디테일

## 예시: 메인 썸네일

```text
제품: 첨부 사진의 스테인리스 텀블러. 모양·색·로고를 그대로 유지.
장면: 흰 배경, 정면에서 살짝 위, 부드러운 스튜디오 조명과 바닥 그림자, 1:1.
문구: 글자 없음.
유지: 뚜껑의 검은색 실리콘 링.
```

## 예시: 상세페이지 1번 히어로

```text
제품: 첨부 사진의 스테인리스 텀블러. 모양·색·로고를 그대로 유지.
장면: 아침 햇살이 드는 사무실 책상, 세로 1080×2160, 위쪽 1/3은 문구 공간, 깔끔한 고딕체.
문구: "출근길에 딱 맞는 500ml" / "머신 텀블러"
유지: 뚜껑의 검은색 실리콘 링.
```

## 수정

- 글자가 틀리면 올바른 문구로 그 이미지 전체를 다시 생성하거나 편집한다.
- 같은 문구가 두 번 틀리면 문구를 짧게 줄여 다시 만든다.
