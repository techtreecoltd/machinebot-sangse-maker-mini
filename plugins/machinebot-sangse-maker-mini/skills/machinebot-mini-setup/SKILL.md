# 설정: 상시 연결

상시 연결은 Codex 전역 지침 파일에 짧은 블록을 넣어, 새 대화에서 상세페이지·썸네일 같은 요청이 오면 항상 머신봇 상세 메이커 mini를 쓰게 하는 설정이다.

## 켜기

1. 무엇이 바뀌는지 알리고 동의를 받는다: "Codex 전역 지침 파일에 머신봇 연결 블록을 추가해요. 새 대화부터 상세페이지·썸네일 요청에 자동으로 연결되고, '상시 연결 해제'라고 하면 언제든 지울 수 있어요."
2. 대상 파일을 정한다. 환경 변수 CODEX_HOME이 있으면 그 폴더, 없으면 홈 폴더의 .codex 폴더다. 그 안에 AGENTS.override.md가 있으면 그 파일, 없으면 AGENTS.md를 쓴다.
3. [연결 블록](assets/always-on-block.md)의 내용을 그대로 넣는다. 파일에 `<!-- machinebot-mini:start -->` 블록이 이미 있으면 그 블록만 새 내용으로 바꾸고, 없으면 파일 끝에 빈 줄 하나를 두고 추가한다. 파일이 없으면 새로 만든다. 블록 밖의 내용은 그대로 둔다.
4. 파일을 다시 열어 블록이 정확히 한 번 들어갔는지 확인하고 "새 대화부터 적용돼요"라고 알린다.

## 끄기

같은 파일에서 `<!-- machinebot-mini:start -->`부터 `<!-- machinebot-mini:end -->`까지만 지우고, 다시 열어 확인한 뒤 알린다.

## 파일을 고칠 수 없을 때

대상 파일 위치와 블록 내용을 보여주고 직접 붙여 넣도록 안내한다.
