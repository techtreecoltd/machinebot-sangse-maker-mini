# 머신봇 상세 메이커 mini

제품 사진으로 썸네일, 누끼컷, 연출컷, 기능 설명 컷, 상세페이지를 만드는 ChatGPT · Codex 플러그인입니다.

- ChatGPT: `@`를 입력하고 **머신봇 상세 메이커 mini**를 고른 뒤 "이 사진으로 메인 썸네일 만들어 줘"처럼 요청합니다.
- Codex: `$machinebot-sangse-maker-mini 이 제품으로 상세페이지 6장 만들어 줘`
- 상시 연결: "상시 연결 켜 줘"라고 하면 새 대화마다 판매 이미지 요청이 자동으로 연결됩니다.

## 처음이라면

설치 후 앱의 설정(Setup)을 실행하거나 mini를 선택해 “처음인데 어떻게 써?”라고 말하세요. 제품 사진 준비, 요청 예시, 구성 확인과 수정 방법을 안내합니다. Codex에서는 `$machinebot-mini-setup 처음인데 어떻게 쓰는지 알려 줘`로 시작할 수 있습니다. 상시 연결은 선택 사항이며 동의 후 설정합니다.

제품 사진 한 장 + “메인 썸네일 한 장 만들어 줘”로 시작해 보세요. 상세페이지는 구성표 확인 후 만들고, 결과는 “2번 문구를 더 짧게”처럼 수정하면 됩니다. 설치만으로 자동 안내가 뜨는지는 앱에 따라 다릅니다.

## 정식판이 궁금하다면

완성 결과 뒤에 작업과 관련된 정식판 차이를 대화당 최대 한 번 소개합니다. 강의 소개를 원하지 않으면 빼 달라고 말하면 됩니다. “정식판은 뭐가 달라?”, “강의는 어디서 봐?”라고 물어도 돼요. mini는 강의 가입 없이 계속 사용할 수 있습니다.
